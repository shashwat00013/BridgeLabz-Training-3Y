Responsive CSS Cheat Sheet

Four useful tools for building adaptable interfaces.

Filters

Change an image's appearance without editing the source file.

filter: grayscale(100%);

Media Queries

Apply styles only when the viewport matches a condition.

@media (max-width: 700px) { ... }

Responsive Design

Let content adapt to available screen space.

width: min(100%, 70rem);

Typography

Scale text smoothly while keeping useful limits.

font-size: clamp(1rem, 2vw, 1.5rem);

Keep the content flexible and the experience readable.
