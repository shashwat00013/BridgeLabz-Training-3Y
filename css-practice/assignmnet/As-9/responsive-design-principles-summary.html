Three Responsive Design Principles

Build interfaces that adapt instead of simply shrinking.

Fluid Layouts

Use relative sizing so content can grow or shrink with the viewport.

width: 90%; max-width: 70rem;

Flexible Media

Keep images and video inside their containers without overflowing.

img { max-width: 100%; height: auto; }

Breakpoints

Change layout when the content needs more or less room.

@media (max-width: 600px) { ... }

Start mobile-friendly, then enhance for wider screens.
