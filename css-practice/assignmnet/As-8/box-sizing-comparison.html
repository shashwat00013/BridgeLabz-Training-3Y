CSS sizing fundamentals

Box-Sizing Comparison

Both examples declare a width of 260px and use the same padding and border.

content-box

Declared width: 260px
Padding: 24px
Border: 8px

The default content-box model adds padding and borders outside the declared width. Total width: 260 + 48 + 16 = 324px.

border-box

Declared width: 260px
Padding: 24px
Border: 8px

The border-box model includes padding and borders inside the declared width. Total width stays 260px.

Use box-sizing: border-box for more predictable layouts.
