CSS Box Model

Every element is a box made from four layers.

MARGIN
BORDER
PADDING
CONTENT
Text or other elements

Content

The innermost area where text, images, or other content appears.

Padding

Space between the content and its border. The padding background is visible.

Border

The line surrounding the padding and content.

Margin

Transparent space outside the border that separates neighbouring elements.

content-box

Width: 220px + padding + border

Default sizing adds padding and border to the declared width.

border-box

Total width: 220px

With border-box, the declared width includes padding and border.

Tip: box-sizing: border-box makes sizing easier to manage.
